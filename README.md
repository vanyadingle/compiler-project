# MiniCompiler — Компилятор MiniLang с визуализатором AST

Учебный компилятор для C-подобного языка **MiniLang**, разработанный в рамках курса по конструированию компиляторов.

## ✨ Возможности

| Компонент | Описание |
|---|---|
| **Лексер** | Полная токенизация: ключевые слова, идентификаторы, литералы, операторы |
| **Парсер** | Рекурсивный спуск + алгоритм Пратта для выражений |
| **AST** | Дерево разбора с сериализацией в JSON |
| **Визуализатор** | Интерактивный веб-интерфейс (Monaco Editor + D3.js) |

## 🚀 Быстрый старт — Визуализатор

```bash
# Запуск одной командой (Flask установится автоматически)
python run_visualizer.py
```

Откроется браузер с интерактивным редактором. Изменяйте код — AST обновляется в реальном времени!

### Возможности визуализатора
- 📝 **Monaco Editor** с подсветкой синтаксиса MiniLang
- 🌳 **Интерактивное дерево AST** — zoom/pan, сворачивание узлов
- 🔤 **Таблица токенов** с цветовой разметкой по типам
- ⚡ **Авто-обновление** при изменении кода (дебаунс 600мс)
- 📚 **5 примеров** (Hello World, Факториал, Фибоначчи, циклы, структуры)
- 🔄 **Два вида** дерева: сверху-вниз и слева-направо

## 📦 Установка (разработка)

```bash
pip install -e .
pip install flask
```

### CLI лексера

```bash
minicompiler-lex examples/hello.src
minicompiler-lex examples/hello.src --format json
```

## 🔧 API визуализатора

```
POST /api/compile
Content-Type: application/json

{ "source": "fn main() { print(42); }" }
```

Ответ:
```json
{
  "tokens": [{"type": "KW_FN", "lexeme": "fn", "line": 1, "column": 1}, ...],
  "ast": {"name": "Program", "children": [...]},
  "errors": []
}
```
