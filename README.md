## **6. `docs/language_spec.md`**
```markdown
# Спецификация языка MiniLang (Спринт 1)

## Лексическая грамматика (EBNF)
letter = "A" | "B" | ... | "Z" | "a" | ... | "z" ;
digit = "0" | "1" | ... | "9" ;
underscore = "_" ;

identifier = letter , { letter | digit | underscore } ;
integer = digit , { digit } ;
float = digit , { digit } , "." , digit , { digit } ;
string = '"' , { character } , '"' ;
boolean = "true" | "false" ;

keyword = "if" | "else" | "while" | "for" | "int" | "float" | "bool" | "return" | "true" | "false" | "void" | "struct" | "fn" ;

operator = "+" | "-" | "*" | "/" | "%" | "=" | "==" | "!=" | "<" | "<=" | ">" | ">=" | "&&" | "||" | "!" ;
delimiter = "(" | ")" | "{" | "}" | "[" | "]" | ";" | "," ;

whitespace = " " | "\t" | "\n" | "\r" ;
comment = "//" , { character } , "\n" | "/" , { character } , "/" ;

text

## Ключевые слова
`if`, `else`, `while`, `for`, `int`, `float`, `bool`, `return`, `true`, `false`, `void`, `struct`, `fn`

## Идентификаторы
- Начинаются с буквы, далее буквы, цифры или подчёркивания
- Длина до 255 символов
- Чувствительны к регистру

## Литералы
- **Целые числа**: последовательность цифр, диапазон 32-битного знакового int
- **Числа с плавающей точкой**: например `3.14`
- **Строки**: в двойных кавычках
- **Булевы**: `true` / `false`

## Операторы и разделители
- Арифметические: `+`, `-`, `*`, `/`, `%`
- Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`
- Логические: `&&`, `||`, `!`
- Присваивание: `=`
- Разделители: `(`, `)`, `{`, `}`, `[`, `]`, `;`, `,`

## Пробелы и комментарии
- Пробельные символы игнорируются
- Однострочные комментарии: `//` до конца строки
- Многострочные комментарии: `/* ... */`
